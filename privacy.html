Privacy Policy

Last updated: 9 October 2026

1. Overview

Clip Uploader is a personal tool used only by its Owner with the Owner's own TikTok account. It does not collect, sell or share personal data of any other person.

2. Data the app handles

  • TikTok access token: When the Owner logs in with TikTok, the app receives an access token that lets it upload video drafts to the Owner's account (scope video.upload). The token is stored only in a configuration file on the Owner's own computer.
  • Twitch clip data: Publicly available clip information (title, streamer name, view count, video) retrieved from the Twitch API.
  • Telegram: Finished videos and captions are sent to the Owner's own Telegram chat via a private bot.

3. What we do not do

The app does not read the Owner's TikTok profile, followers, messages or videos. It does not use analytics, advertising or tracking, and it does not pass any data to third parties other than the services named above (TikTok, Twitch, Telegram), which are used only for the purposes described.

4. Retention and deletion

Temporary video files are deleted right after each upload. The Owner can revoke the app's access at any time in the TikTok app under Settings and privacy, Security and permissions, Apps and services, and can delete the stored token by deleting the configuration file.
